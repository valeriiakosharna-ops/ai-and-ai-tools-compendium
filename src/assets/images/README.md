# Gallery images

The shared mapping is in `content/images.json` (paths relative to `src/`).

- Mercedes: `assets/kimi.png` + `assets/kimi-car.png` → `assets/petronas.png`.
- Oxford: `assets/oxford.png` → `assets/scientists-in-oxford.png`.

To replace an image, keep its filename or update its path and actual dimensions in the mapping. Rebuild to update both languages and all editions. Missing files render labelled placeholders. See `docs/DEVELOPMENT.md` for the full setup and custom-build instructions.
